## What is right

- `tools/report_figures.py --check` is a real guard and it is green. It parses the table rows in `docs/LIMITS.md` (`doc_rows`, `RULES` at `tools/report_figures.py:143-157`) and compares each against the report with a 10% tolerance, and it also catches the label-vs-run mismatch at `tools/report_figures.py:196-204` (`the page says N tabs, the run used M`). `LIMITS.md:7-14` states the guard's own limitation (a failed run on disk does not make a correct page wrong). The uncontracted spot-checks hold: `tabs give their memory back` = `147.8MB ... started at 162.4MB` matches `docs/LIMITS.md:139-140` to the decimal; `20 tabs 441/334` matches; `+13.9 MB` is `(441.3-162.4)/20 = 13.945`.
- Negative claims are stated, not buried. `README.md:104-105` and `LIMITS.md:74-80` both say the blocker is EasyList/EasyPrivacy compiled to a WebKit content blocker and **"It is not uBlock Origin itself: none of that extension's code runs here, so its element picker, its dynamic filtering syntax and its scriptlets are absent."** `README.md:67` and `README.md:99-103` say there is no WebExtensions API, `browser.storage.local` is **not available**, a background page **does not run**, and `docs/ARCHITECTURE.md:83-88` repeats the storage claim. DRM, no autofill, no print dialog, no multiple windows are all in `README.md:73-86`.
- The build instructions are true on this machine. `README.md:126-127` names `webkit2gtk-4.1` (Arch) and `libwebkit2gtk-4.1-dev` (Debian); `pacman -Q` here reports `webkit2gtk-4.1 2.54.2-1`, and `pkg-config` resolves it. The "about 2.8 MB of binary, stripped" claim at `README.md:14` is `2,971,896 / 1024² = 2.83 MB`. The environment claim at `README.md:203` ("4-core desktop with 7.5 GB of RAM, as `nproc` and `/proc/meminfo` report them") is exactly `nproc` 4 and `MemTotal 7857856 kB`, and both tools are named so a reader can re-run them.
- The memory section does not lead with the flattering number. `README.md:16-22` leads with **159.0 MB resident** and only then names 49.4 MB as `Pss_Anon`, names the 9.9 MB of shared backing separately, gives the 49-119 MB range as a range, and `docs/LIMITS.md:43-52` spells out that resident is mostly the engine and that "the flattering number cannot hide" the gap (`docs/ARCHITECTURE.md:147`). The Firefox comparison at `README.md:166-169` is explicitly labelled "one afternoon's comparison rather than a benchmark" and says no script in the repository produces it.

## What costs points

- **Tab reordering does not exist and no document says so.** `grep -rn -i "reorder|move_tab|drag_source" src/*.rs` returns nothing; the only `set_position` calls are `src/app.rs:210` (`window.set_position`) and `src/app.rs:313` (`paned.set_position`). The tab context menu is three items, `src/app.rs:1819-1821`: `Pin Tab`, `Duplicate Tab`, `Close Tab`. The nearest the docs come is `README.md:84` "**No multiple windows and no tab dragging between them**", which reads as *between windows* and therefore implies dragging within one window works. This is the one defect a switcher hits in their first minute, and `grep -rn -i "reorder|order of tabs|drag a tab" README.md docs/ CHANGELOG.md` finds nothing. *Smallest fix:* one bullet in `README.md` "What it does not do", after line 84: `**No reordering by dragging.** Tabs are in the order they were opened; the context menu has pin, duplicate and close. New tabs go to the end.` *Cost: 0.7.*
- **`assets/shield-rules.json` is a dead file that contradicts the blocker.** It is tracked (8.3 KB, 75 rules) but nothing in `src/` or `tools/` reads it: `grep -rn "assets/shield-rules" src/ tools/` is empty, and `src/shield.rs:57` writes its readable copy to `data_dir()/shield-rules-{hash}.json`, not here. `tools/build_shield.py:289-299` writes only `network.json` and `hide-0.json`, and `:283-284` deletes everything else in `OUT` (`for old in OUT.glob("*.json"): old.unlink()`). It was last touched at commit `18ab831`. A reader who opens it, as `README.md:127` invites ("The compiled rule list is a JSON file you can read"), sees 75 rules where the shipped list has 14,000 network rules and 2,626 selectors. *Smallest fix:* `git rm assets/shield-rules.json`. *Cost: 0.4.*
- **`docs/ARCHITECTURE.md:112-117` line counts are wrong for 10 of 22 files and understate the tree by 1,174 lines**, in a sentence that begins "Measured with `wc -l src/*.rs` **at this commit**". `app.rs` 2,531 claimed / 2,813 actual; `css.rs` 242 / 492; `ui.rs` 582 / 705; `web.rs` 544 / 695; `panels.rs` 929 / 1,148; total 11,195 claimed / 12,369 actual. - **`docs/DIFFERENCES.md:39` quotes a resident figure no run produced: "about 208 MB for one tab"**, against 159.0 MB in the report, in `docs/LIMITS.md:24`, in `docs/ARCHITECTURE.md:144` and in `README.md:17`.
