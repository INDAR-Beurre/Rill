## What is right
- Every sentence is the browser's own, for every way a page can fail: HTTP status in `src/web.rs:597-612`, transport errors in `src/web.rs:614-640`, process death in `src/web.rs:594-604`, refused scheme in `src/web.rs:307-330`. `09-missing.png` shows exactly "That page did not open" / "There is nothing at this address (404)." / `http://127.0.0.1:8099/missing` in mono at `y 410-480`; no word in that block came from WebKit.
- Failure is per tab and never repaints another tab: `state.errors` is keyed by `TabId` (`src/app.rs:2002-2020`), `show_error` returns after `render_rows()` when the tab is not active, and `render()` tests `has_error` before `blank` (`src/app.rs:755-760`). The pass details "active 3 showing tab-3" and "3 tabs, 3 with a view" match the code.
- The one action is chosen by the failure. A 404 gives "Change address", which clears the entry, opens the field and pre-selects the whole failed URL (`src/app.rs:2109-2120`); a 5xx or a transport error gives "Try again" and `retry()` reloads the stored address (`src/app.rs:2074-2091`). The label in `09-missing.png` reads "Change address" for a 404 exactly as `error_action` decides.
- Contrast holds on both pages in both appearances with no exception: title `#646462` on white 5.93:1, reason 5.93:1, address `#5E5E5E` 6.48:1, button label `#171717` on `#EFEFEF` 15.59:1, and in dark title `#A6A6A6` on `#0B0B0B` 8.09:1; the drawn field's `#949492` edge is 3.04:1 light / 3.41:1 dark, above the 3:1 a non-text edge needs.

## What costs points
- **The start page draws a field, and it is not the field.** The drawn box is `340x36` at `x 696..1035, y 467..502`, 1px `#949492`, radius 9, fill `#FFFFFF` (the page's own white, so only the border reads). The real field is `560x50` at `x 586..1145, y 191..240`, radius 12 (`src/omnibox.rs:8-9`, `:181`; `src/css.rs:288`). So Escape from the field and then Ctrl L moves the box `276px` up the page, widens it `220px` and changes its corners. The strings differ too: `src/ui.rs:236` "Search or enter an address" against `src/omnibox.rs:193` "Search or enter address". The drawn box is an `EventBox` with no press handler of its own (`src/ui.rs:225-247`) and `.fakefield:hover { border-color: {faint} }` (`src/css.rs:277`) paints hover on a non-control; only the holder behind it opens the field (`src/app.rs:2512`). Costs about -1.0. Smallest fix: give the fake field `FIELD_WIDTH`/`FIELD_HEIGHT` and the entry's placeholder, and anchor the block where `plan()` puts the field.
- **Neither page takes a keystroke.** `Key::intent` (`src/keys.rs:82-148`) has no printable-character branch and `Intent::Nothing => {}` (`src/keys.rs:218`) is the whole of the fallback, so on the page whose entire purpose is starting to type, typing does nothing. Nothing on either page is focusable: the retry button is `gtk::Button::with_label` with no `set_can_focus` (`src/ui.rs:272-275`), `src/css.rs` has no `:focus` rule for `.blank button.act` (only `.omni.focused` and `.omni entry:focus`, `src/css.rs:289-293`), and `show_error` never `grab_focus`es anything (`src/app.rs:2002-2045`). The Ctrl L keycap at `x 697..1025, y 468..493` is the page admitting it cannot hear you. Costs about -0.9.
- **A failed tab carries no state in the column, and the row you are on loses its ink.** `TabState` holds `asleep`, `loading`, `private` and nothing else (`src/ui.rs:503`), `tab.failed` never reaches a widget (`src/app.rs:868-878`), and no `.row.failed` rule exists, so the 404's row in `09-missing.png` reads `127.0.0.1` in faint ink with no mark. Worse, the active row's ink is wrong in that state: it measures `#878786`/`#6A6A68` against `#0E0E0E` for the active row in `08-empty.png`, because `liveword` is added when the row is built (`src/ui.rs:601-609`) while the fast path only toggles `.live` on the event (`src/app.rs:813-828`). A row built for another tab and then made active keeps resting grey, so "you are here" is dark on one page and grey after a failed load. Costs about -0.7.
- **The failed address cannot be taken away.** `error_address` is `EllipsizeMode::Middle` with `max_width_chars(52)` and no tooltip (`src/ui.rs:268-271`), and `set_selectable` is called nowhere in `src/` (0 hits), so the one thing a person wants from a broken page, the URL, cannot be selected, copied, or read past 52 characters. Costs about -0.4.
- **The start page offers nothing to start from.** No recents, no bookmarks, no frequently visited, while every panel in the product has a written empty state (`src/panels.rs:309-516` through `empty_state`, `src/panels.rs:909-912`). The tab that is "a place to start" is the emptiest screen in the app, and `README.md:4` still promises "no start page" while `08-empty.png` draws a titled one. Costs about -0.4.
- **One action, no way back.** The block has a single `138x32` button at `x 797..935, y 502..533` and no "Go back" even when `can_back` is true; Escape on this page is bound to nothing (`src/keys.rs:213-217` closes a field, find, a panel or the reader, otherwise stops a load). After a 404 the exits are Ctrl L and Alt+Left, neither of which the page says. Costs about -0.2.
- **The block staircases.** Each line is centred on `x=866` but the widths differ (title 187, reason 208, address 250, button 138), so the left edge steps right by 56px and back again; a centred column of unequal lines reads as an accident rather than a hierarchy. Quarter point.
- **The light cut corner shows on the two emptiest pages.** `council/round-33-dark/08-empty.png` and `09-missing.png` both carry `srgb(234,234,233)` at `(0,27)` against the `#0A0A0A` band, 16.46:1, hardcoded at `src/app.rs:2675`. Already filed under dark; not charged here, but it is visible in this facet's only two pictures.

## The three changes that would raise this score most
1. Make the drawn field the real field's twin: `FIELD_WIDTH`/`FIELD_HEIGHT` (`src/omnibox.rs:8-9`), the entry's placeholder (`src/omnibox.rs:193`), radius 12, and anchor the title-and-box block where `plan()` places the field, so Ctrl L lights the box up in place instead of replacing it 276px away at a different size.
2. Make both pages hear the keyboard: add a printable-character branch to `Key::intent` (`src/keys.rs:82`) returning `Intent::Omni` while the stack shows "blank" or "error" so a letter opens the field with that letter in it; give the error page's action a focus (`error_retry.set_can_focus(true)`, `grab_focus()` in `show_error` at `src/app.rs:2039`) with a `.blank button.act:focus` outline, and route Return to `error_pressed`.
3. Give failure a face and a copy: carry `failed` into `TabState` (`src/ui.rs:503`), add `.row.failed` with a mark in the tile, sync `liveword` in the fast path (`src/app.rs:818-826`) so the active row is dark in every state, and make `error_address` selectable with the full URL in a tooltip.
